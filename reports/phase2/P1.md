## 2. What Was Missing

1. **Clean `Probe` Facade:** No unified top-level `Probe` class providing ergonomic access to all 9 instruments and shared subsystems (`Probe.meter`, `Probe.scope`, `Probe.freqscope`, `Probe.spectrum`, `Probe.spectrogram`, `Probe.waterfall`, `Probe.history`, `Probe.loudness`, `Probe.vectorscope`, `Probe.dashboard`, `Probe.theme`, `Probe.fontScale`, `Probe.broker`).
2. **Non-Conflicting Server Convenience Methods:** No zero-overhead convenience calls on `Server` (`s.meter2`, `s.scope2`, `s.freqscope2`, `s.spectrum`, `s.spectrum2`, `s.spectrogram`, `s.waterfall`, `s.history`, `s.loudness`, `s.vectorscope`, `s.dashboard`, `s.spectralDashboard`, `s.bandAnalyzer`).
3. **Core SC Invariant Protection:** Strict verification that vanilla `s.meter`, `s.scope`, and `s.freqscope` are never overridden or shadowed by extension files.
4. **Probe Quark Metadata:** A clean `Probe.quark` package specification (v0.2.0) defining the suite under its new identity.
5. **Window Title Branding:** Visualizer windows and dashboard headers retained legacy `"SCVisuals"` text rather than `"Probe"`.
6. **Qt Teardown Null-Safety:** Closing visualizer windows occasionally triggered Qt resize notifications where `v.bounds` was `nil` during child widget destruction, logging transient `DoesNotUnderstandError: Message 'width' not understood`.

## 4. Architecture Chosen and Alternatives Rejected

- **Chosen: Primary Facade (`Probe`) with Retained Internal Classes (`SCV...`):**
  - *Rationale:* Mechanical renaming of every file/class from `SCV` to `Probe` risks breaking user code, third-party presets, and git history with zero runtime gain. Providing `Probe` as the primary public facade ensures clean, modern ergonomics while preserving 100% backwards compatibility for existing code using `SCVisuals.*` or `SCVMeter.*`.
- **Chosen: Numeric Suffix Shortcuts (`s.meter2`, `s.scope2`, `s.freqscope2`):**
  - *Rationale:* Core SuperCollider already claims `s.meter`, `s.scope`, and `s.freqscope`. Overriding them would violate SuperCollider community invariants, break third-party extensions, and alter default behavior. Suffixing with `2` follows SuperCollider precedents (e.g., `ScopeOut2`, `LinXFade2`) and provides instantaneous, intuitive discovery.
- **Rejected: Overriding `s.meter` or Aliasing `Monitor`:**
  - *Rationale:* The namespace audit in Gate G0 confirmed that `Monitor` is a critical JITLib core class (`InBus.sc`). Any collision would corrupt SuperCollider's node proxy routing.

## 9. Known Limitations and Portability Constraints

- `s.scope2` and `s.freqscope2` rely on SuperCollider's shared-memory `ScopeView` (`ScopeOut2`). When used with a remote server over network OSC, standard scope buffer shared-memory is unavailable; `Probe.history` or `Probe.loudness` should be used instead for remote telemetry.
- Window bounds at 125% scale remain compact; full dynamic layout reframing is scheduled for later per user guidance.
