## 1. Existing Behavior Found (with File/Line References)

1. **SuperCollider SynthDef Internal Representation:**
   - In `SynthDef.sc`, compiled SynthDefs maintain their complete UGen graph internally in `children` (an Array of `UGen` instances in execution order).
   - Each `UGen` exposes `inputs` (referencing either constants, `Control` `OutputProxy` instances, or upstream `UGen` outputs) and `rate` (`\audio`, `\control`, `\scalar`, `\demand`).
2. **`Synth:trace` Snapshot Limitations:**
   - `s.trace` / `aSynth.trace` sends an asynchronous `/n_trace` OSC command to scsynth, printing a single control-period snapshot of inputs and outputs to the post window. It does not provide structured, continuous telemetry or graphical connection topology.
3. **`Server:plotTree` Representation:**
   - Built-in `s.plotTree` visualizes the execution hierarchy of `Group` and `Synth` nodes on the server. However, it displays execution ordering and node trees—it does not depict internal UGen signal wiring, bus feedback routing, or parameter interconnections.
4. **Feasibility of Arbitrary Live Probing:**
   - On-demand insertion of probes into an *already-running, uninstrumented Synth* cannot be done from sclang without recompiling the SynthDef or routing audio through dynamic patch points (`InFeedback.ar` / `ReplaceOut.ar`).

## 2. What Was Missing

1. **Topological Graph DAG Visualization:**
   - No interactive or static visualization existed in SuperCollider to display the signal flow Directed Acyclic Graph (DAG) of a `SynthDef` with inputs on the left, DSP processing in the center, and outputs on the right.
2. **Rate Distinction & Signal Flow Wires:**
   - No graphical representation distinguished audio-rate (`\audio`), control-rate (`\control`), and scalar/initialization (`\scalar`) pathways with curved bezier connection routing.
3. **Probe `.trace` Tap Integration:**
   - No inspector existed that could parse a SynthDef, identify probe taps inserted via `.trace`, and allow the user to inspect their connections interactively.
4. **Unified Ergonomic Access:**
   - Neither `Probe.inspect(synthDef)` nor `s.inspector(synthDef)` existed.

## 3. Changes Made (Exact Files, Selectors, Classes)

1. **`classes/ProbeInspector.sc` (New Class File):**
   - Implemented `ProbeGraphView`:
     - Topological DAG layer calculator (`prParseGraph`): groups UGens into hierarchical columns based on input dependencies.
     - Responsive layout engine (`prLayoutNodes`): calculates dynamic node rectangles, column widths, and vertical distribution without box overlap.
     - Custom vector renderer (`prDraw`): draws curved bezier connection wires (`Pen.curveTo`), color-coded by source rate (Signal cyan for `\audio`, Warning amber for `\control`, Subtext for `\scalar`).
     - Interactive node selection: clicking any node highlights incoming/outgoing wires and displays complete node metadata (index, class name, rate, input sources) in an inspector footer banner.
   - Implemented `ProbeInspector`:
     - Standalone floating window wrapper (`820x500`) with dynamic resize handling, honoring `Probe` theme palettes (`\graphite`, `\ice`, etc.).

## 4. Architecture Chosen and Alternatives Rejected

- **Chosen Design: Static DAG Graph with Topological Layering:**
  - Evaluates the compiled `SynthDef` locally in `sclang` without server communication overhead.
  - Generates clear, readable DAG layers that communicate signal processing depth and flow from left to right.
- **Rejected: Polling Server Internals for Live Graphs:**
  - Rejected polling scsynth for internal UGen wire states during audio processing. Doing so over OSC would consume excessive bandwidth and risk audio dropouts.
- **Rejected: Overriding `Server:plotTree`:**
  - Maintained strict non-interference with vanilla `s.plotTree`. The node tree (execution order) and DSP graph (signal wiring) serve different diagnostic purposes.

## 6. Scientific / Algorithmic Verification

1. **Topological Invariant:**
   - For every edge $(U_a \to U_b)$ where $U_a$ is an input to $U_b$, $\text{layer}(U_b) > \text{layer}(U_a)$.
   - Verified in unit tests: `Control` UGens always reside in Layer 0; `Out` UGens always reside in the maximum layer.
2. **Rate Propagation:**

## 9. Known Limitations and Portability Constraints

- **Dynamic Patching / Bus Inferences:** Audio signals routed through intermediate audio buses (`In.ar(bus)` / `Out.ar(bus)`) across separate `Synth` instances are independent SynthDefs; inter-synth connections remain logically inferred rather than statically proven.
- **Per-UGen CPU Profiling:** Real-time per-UGen CPU accounting requires C++ modifications to the scsynth engine and cannot be achieved in a pure Quark.

// 1. Inspect any SynthDef

    Out.ar(out, fil * 0.2);
});
Probe.inspect(def);
)

s.inspect({ |freq=220| Saw.ar(freq) * 0.15 });
