## 2. What Was Missing

1. **Dedicated Spectral Band Analyzer:** A true 16-band calibrated logarithmic band analyzer displaying ISO-standard frequency bands (31 Hz to 16 kHz) with segmented bar meters, peak-hold indicators, and frequency labels.
2. **Unified Shared Spectral Source:** A single reference-counted analysis synth per monitored bus that computes FFT-based descriptors (Centroid, Flatness, Roll-off, Flux/Onsets), pitch tracking (`Pitch.kr`), chromagram, and band powers without spawning duplicate FFT chains.
3. **Advanced Spectral Dashboard:** A unified, theme-aware laboratory console with four preset configurations:
   - **Overview:** FFT Spectrum + 16-Band Analyzer + 4 Descriptors HUD.
   - **Pitch & Chroma:** Fundamental f0 Tracker + 12-Tone Chromagram.
   - **Time-Frequency:** Rolling Spectrogram + 3D Waterfall.
   - **Compare:** Live vs Reference Hold / Differential Spectrum.
4. **Zero-Reallocation Panel Architecture:** Tabbed layout that avoids deleting and re-creating Qt ScopeViews or ScopeBuffers during preset switching, ensuring seamless, glitch-free operation.

## 4. Architecture Chosen and Alternatives Rejected

- **Chosen: Single Shared Spectral Source (`ProbeSpectralSource`):**
  - *Rationale:* Running separate FFT chains for Spectrum, Centroid, Flatness, Roll-off, and Pitch would waste substantial CPU. Grouping the descriptors into a single reference-counted synth via `SCVMeasurementBroker` minimizes audio thread overhead while feeding all overview panels simultaneously.
- **Chosen: Persistent View Panels with Show/Hide Toggling:**
  - *Rationale:* Recreating Qt widgets and reallocating `ScopeBuffer` instances during rapid preset switching risks buffer index collisions and teardown warnings. Keeping the panels persistent and toggling `visible = true/false` delivers instantaneous, zero-cost tab switching.
- **Rejected: Heavy Native C++ Plugin Rewrite for Descriptors:**
  - *Rationale:* Existing optimized SuperCollider primitives (`SpecCentroid`, `SpecFlatness`, `SpecPcile`, `Pitch`) run with high efficiency. Leveraging them inside a unified synth preserves Quark portability across macOS, Linux, and Windows without requiring external binaries.
